# EDA.NUMPY
Exploratory Data Analysis of House Prices (Ames Housing)
Objective
Explore the Ames Housing dataset to understand the factors associated with house sale prices using EDA only (no machine learning).
Dataset
Kaggle competition: House Prices: Advanced Regression Techniques
Download train.csv from Kaggle and upload it to the notebook when prompted.
Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Google Colab / Jupyter Notebook
Workflow
1. Setup and first look
2. Classify variables
3. Descriptive statistics
4. Distribution plots
5. Correlation and covariance
6. Scatter plots and pair plot
7. Correlation heatmap
8. Outlier detection using IQR and Z-score
9. Data quality checks and missing-value handling
10. Dashboard and conclusions
How to run
1. Open EDA_House_Prices.ipynb in Google Colab.
2. Download the Kaggle train.csv dataset.
3. Run notebook cells from top to bottom.
4. Upload train.csv when prompted.
5. Review outputs and fill the conclusion section using your actual observations.
Outputs
- eda_dashboard.png
- ames_housing_cleaned.csv
Important
This notebook is exploratory analysis only. Correlation does not imply causation, and statistical outliers are not automatically data errors. Document any cleaning decisions.
